Seleção de perfil

A lista permite escolher Conservador, Moderado ou Agressivo, mas os percentuais atuais estão fixos. Precisamos fazer com que a divisão do aporte mude conforme o perfil.



Fórmula PROCV

Não encontrei essa fórmula na planilha. Ela precisa ser utilizada para buscar os percentuais correspondentes a cada perfil, conforme o modelo da atividade.



Intervalo nomeado com erro

O nome patrimonio está associado a uma referência inválida (#REF!), que precisa ser corrigida.
